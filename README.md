# 🍷 Red Wine Quality - Exploratory Data Analysis (EDA)
## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Red Wine Quality dataset, which contains physicochemical measurements of red Portuguese "Vinho Verde" wines. The primary objective is to uncover meaningful patterns, relationships, and insights that explain how chemical properties influence wine quality.

## 🧪 Dataset Description
The dataset contains 12 variables:

11 input variables: physicochemical tests such as acidity, pH, alcohol, sulphates, etc.
1 output variable: wine quality, a score between 0 and 10 (based on sensory data).


📂 Source: UCI Machine Learning Repository
📄 File used: winequality-red.csv


## 🎯 Problem Statement
To explore how physicochemical properties of red wine affect its quality score and to identify key factors that contribute most to wine quality through visual and statistical EDA techniques.

## 📊 Key Questions Explored
1. What is the distribution of wine quality scores?
2. How are individual features distributed? Are there outliers?
3. What are the correlations between features and wine quality?
4. Which features are most influential in determining quality?
5. Are there patterns that differentiate high-quality wines from lower ones?

## 🔍 EDA Techniques Applied
i) Descriptive Statistics
ii) Univariate & Bivariate Analysis
iii) Correlation Matrix and Heatmap
iv) Boxplots, Histograms, and Pairplots
v) Group-wise comparisons (e.g., alcohol vs. quality)
vi) Outlier detection and insights

## 📌 Key Insights
1. Alcohol and sulphates show a strong positive correlation with wine quality.
2. Volatile acidity has a negative correlation with quality.
3. Most wines are rated between 5 and 6, indicating a class imbalance.
4. Certain features such as pH and density show minimal variation across quality levels.
